## 修订原因与画面

v0.3 已在 6.0 秒准确断离，但断后夹具持续移动；v0.4 修正为断后停机，却仍使用水平平直断面。用户分别指出这两种视觉与正常金属断裂观感不符。v0.5 保留金属扁平哑铃形试样、正面固定机位、脆性断裂、`inside_gauge` 和视频标签，采用八个不等距横向样本构成轻微斜向、非周期性的互补不规则断口。轮廓起伏控制在 `-0.065W` 至 `+0.075W`，避免机械直切和规则卡通锯齿。

Blender 第 181 帧首次完全断离时，上夹具和横梁冻结于累计位移 `0.42W`。断口逐点初始间隙为 `0.62W`，自由端仅在三帧内完成额外 `0.10W` 的局部卸载，随后逐点间隙稳定为 `0.72W`，夹持端不回弹、不滑脱。正式编码前检查 f1、f180、f181、f184、f210 和 f300；所有断后轮廓均为简单闭合多边形，无退化边或自交。f181 的部件包围盒净空为 `0.465W`，f184 之后为 `0.565W`。

主 Agent 与视觉专职 Agent 实际查看了编码 f180/f181/f184/f210/f300：f180 仍连续且无明显颈缩；f181 的斜向不规则断口在 854×480 编码后清楚可辨并已完全分离；f184 至片尾的试样、间隙和夹具位置保持稳定，没有继续拉伸或重新接合。历史真实参考 `video_0041` 的视距只能支持突然分离与无明显颈缩，不能定量标定断面；本断口是明确记录的视觉近似，不是对真实断口几何的测量复刻。
