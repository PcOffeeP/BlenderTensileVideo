## 修订原因与画面

v0.3 已在 6.0 秒准确断离，但上夹具在此后持续移动、断口间隙一直增大。用户指出这不符合正常拉伸实验中拉断后夹具停机的观感。v0.4 保留金属扁平哑铃形试样、正面固定机位、脆性断裂、`inside_gauge` 与全部视频标签，把上夹具和横梁在 Blender 第 181 帧首次完全断离时冻结于累计位移 `0.42W`。断口首帧间隙 `0.62W`，仅自由端在三帧内完成额外 `0.10W` 的局部卸载，此后几何间隙稳定为 `0.72W`，夹持端不回弹、不滑脱。

正式编码前检查初始 f1、断前 f180、首次分离 f181、卸载结束 f184、断后 f210/f300。几何门禁显示 f181 的部件边界间隙 `0.620W`，f184、f210、f240、f270、f300 均为 `0.720W`，断口到肩部的轮廓没有 Z 向折返。主 Agent 与视觉专职 Agent 都查看了实际编码的 f180/f181/f184/f300：断前连续，断离在相邻帧间发生；f184 与片尾的试样和夹具位置一致，没有继续拉伸或重新接合。
