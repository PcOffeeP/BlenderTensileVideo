# 虚拟拉伸试验视频设计与制作流程

设计版本 v1.15。后续批次依次确定用途、选定适用的拉伸行为、配置参数、制作与检查、审核标签、按用途收录。本文维护跨批次的行为与验收规则；各参数的定义、候选值及测量方法集中在[视频生成参数与测量规范](video-generation-parameters.md)。

## 1. 项目目标与交付

用 Blender 批量制作金属、高分子、复材和陶瓷试样的拉伸视频，为多模态模型提供可追溯的整片样本。每批先说明用途、要覆盖的行为差异、需要从画面判读的现象，以及视频要呈现的时间区间。例如，覆盖完整加载过程与考察“首帧已经断开”的判读能力，对首帧和断前证据的要求不同。

一条样本以稳定 ID 关联 MP4 和同名 JSON。视频呈现宏观形变与破坏，JSON 记录生成配置、行为依据、假设与未知、时间映射、实际检查、标签及确认范围。定性动画所支持的结论限于已核验的行为与画面。切片重标、模型接口适配、训练和测评运行由下游流程处理。

## 2. 拉伸行为规则与参数搭配

### 2.1 材料与条件对应的典型行为

先写清**材料及状态、内部结构与方向、试样几何、夹持与加载条件**，据此选择断前形变、破坏事件和断后状态。整理新规则时，写明适用条件、行为顺序、依据及其支持范围。试验方法用于核对试样和测量对象；材料理论、匹配条件的研究或连续实验记录用于判断行为；相机固定、设备断后停止等演示设定单独注明。条件一致的变体可以复用这份依据。

| 适用条件 | 成片应呈现的行为 | 选择这个规则需要确认什么 |
|---|---|---|
| 单轴拉伸、选定局部颈缩韧断行为的延性金属光圆棒 | 先伸长，随后变形集中在颈部，完整截面逐步缩小，最终失去贯通连接。 | 颈缩与试样形状、材料状态相符；平板另核厚度和宽度方向的变化。金属试验中的伸长和断面收缩测量见 [ASTM E8/E8M](https://store.astm.org/standards/e8_e8m)，圆柱试样的局部化过程见 [Bower §9.2.6](https://solidmechanics.org/Text/Chapter9_2/Chapter9_2.htm)。 |
| 已选定大伸长行为的柔性高分子试样 | 加载时自由段伸长；若该样式有断后卸载或摆动依据，自由段有限运动、衰减并停止。 | 区分大伸长、局部颈缩和颈缩传播。薄膜夹口根部破坏还要核对夹口边界与断口位置。 |
| 选定小变形脆断行为的陶瓷或其他试样 | 断前变形有限，按适用样式出现局部开裂或快速全断。仍连接和已经全断对应不同末态。 | 核对裂纹发展是否属于该样式，以及视频实际覆盖哪一段。独立合成陶瓷的相邻帧突断是该系列的演示设定。 |
| 选定同步断裂与界面脱粘的复材试样 | 断裂开始时界面同时打开，随后共同发展，末态完全断裂。 | 记录组分、结构、加载方向及已知的界面依据。该次序适用于所选同步样式；其他破坏次序另按条件建立规则。 |

检索试验方法时，金属可从 ISO 6892-1 或 ASTM E8/E8M 入手，塑料、薄膜和橡胶分别查 ASTM D638、D882 和 D412，适用的层合复材查 D3039/D3039M，单体先进陶瓷查 C1273。采用时核对具体版本和适用范围。动画中的颈缩幅度、裂纹帧数或碎片速度需要各自的依据或作者设定。

独立合成系列使用作者设定的材料和场景，直接复用适用的行为规则，不从真实实验画面或历史样片继承外观与动作。该系列金属韧断采用伸长、局部颈缩、整截面相邻帧突断的顺序。引用实验的样式则保存来源标识、画面观察与时间映射；既有测试来源仅供历史追溯。

### 2.2 固定条件与参数联动

| 当批次改变…… | 须联动或保持的条件 |
|---|---|
| 伸长、颈缩程度或位置 | 在同一材料段上协调轴向伸长、截面收缩和加载端行程。正常夹持时材料夹持段始终随实际夹口运动。模型采用体积近似时核对该段体积；卸载后保留已设定的不可逆变形。 |
| 破坏位置或脱粘范围 | 在初始材料坐标中移动整个破坏区，检查其两端与标距、肩部、夹口的关系。同步脱粘样式同时检查开口、厚度、连通性和穿透。 |
| 事件时间或帧率 | 按样式重排加载、开裂、失贯通和断后阶段，保持先后或同步关系。按实际输出帧率重算帧号，确认观察窗口足以支持本批目标。 |
| 断后条件或呈现方式 | 停止加载的场景保持夹具停止；样式要求静止时断片停止，有衰减运动时保留固定端约束。换构图、外观、光照后检查夹口和破坏区仍清楚；单片内相机位置、朝向、视场与尺度固定。 |

### 2.3 参数替换的适用边界

改变颜色、背景或固定视角，通常可沿用原行为，但要重看关键线索。改变材料状态、铺层方向、缺口、夹持状态或加载条件，先重新判断原行为的适用性。整段结果、主要类别、位置类别或异常标签改变时，按新组合制作和审核首例。缺少适用依据的组合保留缺项，其他有依据的组合可以继续。

针对局部开裂、未夹紧和爆炸性断裂，沿用各自的场景设计、可见性要求和五类人工审核口径。滑移或脱出时分别检查试样与夹口的相对运动和试样自身连接状态。[特殊标签视频设计](virtual-eval-supplement-design.md)

## 3. 依据行为规则选择参数与设计批次

1. **选择基准。** 写清本批适用的第 2 章规则和观测目标，按参数表 A–C 确定材料、结构、几何和装置，再选匹配的生成入口。新样式先做基准样片。[参数表与模板](video-generation-parameters.md#模板代号) · [生成器说明](../generator/README.md)
2. **选择变量。** 从 D–G 选本批要改变的形变、破坏、断后或时间参数，从 H–J 选适用的呈现条件。逐个写明基准值、候选值、固定项、联动项和比较方法。以断裂行为为目标的批次优先覆盖可判读的行为差异。
3. **验证后再组合。** 先检查单参数离散值，再对拟采用的完整组合单独检查。参数表列出的候选值、生成器支持的输入和实际核验过的配置分别记录。有限样片只支持其已检查的条件和范围。
4. **按有效差异取样。** 在同一阶段对比基准与变体。仅事件时间变化的样本计作时序变化；形变覆盖须有实际测量及可见差异。失败时返工或缩减该组，实际收录数量随通过结果确定。

**示例：同一金属圆棒的颈缩程度。** 采用第 2.1 节的圆棒行为，固定材料状态、几何、夹持、破坏位置和相机，只选择 D4 的离散候选。随局部伸长调整截面及加载端位移，在首次开裂前比较同一材料位置的完整截面积比，观察颈部附近的伸长是否相应集中。若要同时改变 G4 失贯通时刻，再检查组合后的事件顺序和断后观察时长。[D4 与事件测量方法](video-generation-parameters.md#测量与时间对应)

## 4. 制作与技术核验

在 `_work/<任务>/` 保存实现版本、完整配置、关键状态和检查证据。先看关键状态能否表达目标，再生成连续动画和最终编码。每条候选均核对以下三层。

| 核验对象 | 实际检查 |
|---|---|
| 装置与求值网格 | 沿过程检查实际夹口接触、端到端材料连通性、同一材料段长度及截面、适用体积、裂区位置、间隙与穿透。完整设备取景还要检查夹具与传力杆、横梁或固定座全程连接。检查采用实际几何，并注明原生连接或重合界面的判定方法。 |
| 事件与断后运动 | 测量首次开裂、最终失贯通和首次肉眼可辨全断的各自时刻，核对夹具、断片及自由段的停止或衰减。首帧已断的片段只能直接看到起始状态；末帧才断的片段无法观察后续运动。把可见窗口与生成设定分别记入 JSON。 |
| 编码与画面 | 完整解码，核对分辨率、帧率、帧数、时长和事件帧与 JSON 的一致性。主 Agent 实际打开最终视频和必要的关键状态，检查运动连续、夹口清楚、断面可辨以及异常是否确属目标现象。 |

## 5. 标签判定与人工验收

整条视频保存六组预期标签及逐项核验结论。材料身份来自来源、用户确认或明确的独立合成设定；其余各组依据实际过程、几何和最终画面的可见范围判断。

| 标签组      | 取值                                   | 判定边界                                                                |
| -------- | ------------------------------------ | ------------------------------------------------------------------- |
| 材料类别     | 金属、高分子、复材、陶瓷、无法确认                    | 依据来源材料信息，不从颜色或纹理推断。                                                 |
| 断裂结果     | 未呈现破坏、局部破坏但仍连接、完全断裂、无法确认             | 依据整条视频结束时的结果；事件过程另行记录。                                              |
| 单一主要破坏类别 | 韧性断裂、脆性断裂、界面脱粘、爆炸性断裂、半脆半韧断裂、不适用、无法确认 | 只记录一个主要类别；无法合理归类时不强行打标。                                             |
| 断裂位置     | 标距内、标距外非根部、夹口根部、不适用、无法确认             | 与破坏类别分开；对应位置标识 `inside_gauge`、`outside_gauge_non_root`、`grip_root`。 |
| 夹持异常     | 无、未夹紧、无法确认                           | 滑移、脱出等具体表现写入说明，不另设主标签子类。                                            |
| 拍摄异常     | 无、视频异常、无法确认                          | 遮挡、重取景等具体表现写入说明，不另设主标签子类。                                           |

局部损伤、完全失贯通、首个可见间隙分别记录；伸长或颈缩本身不足以判定损伤。位置覆盖整个破坏区，注明正式标距或作者定义的区域。齐根描述位置。对象不存在时依上表使用“不适用”；证据不足时使用“无法确认”。

项目的半脆半韧视觉判据为断前逐渐且视觉上均匀地伸长、无明显局部颈缩，最终快速断裂。丝束爆炸性断裂须能看出试样自身快速炸裂、散开或广泛破坏，仅有亮度变化、附件运动或毛束状展开均不足以确认；独立自由碎片属于可选表现。两类视觉判据均只支持所记录的宏观现象。

材料行为和标签依据按[项目工作约定](../AGENTS.md)独立复核，记录与生成预期的差异。首批逐条由用户看效果和标签；后续仅在已确认样式和范围内对常规变体分层抽样，发现问题扩大同组检查。新样式、扩大范围或新标签组合先确认首例。分别记录技术检查、画面确认、标签确认和用途资格。制作错误返回工作区返工。

## 6. 送审、收录与追溯

- **送审。** 将可播放的 MP4 与同名 JSON 放入 `review/<批次>/`，记录适用规则、来源或作者设定、实现与完整配置、时间映射、实测与未知、预期和已核验标签、确认范围。当前候选以各自的 JSON 为准。[审核目录](../review/)
- **收录。** 按用户确认的用途纳入 `datasets/<版本>/`。核对 `videos/<id>.mp4`、`metadata/<id>.json`、`labels.csv` 和 `manifest.json` 之间的 ID、相对路径和校验值。后续标签修订由清单绑定原元数据及确认依据；已交付版本保持成员边界。下游按实际切片重新判读。[数据集](../datasets/) · [标签导出说明](../generator/README.md#统一视频标注导出)
- **追溯。** 当前交付与待审入口查项目 README。V1 的单参数、组合和首批数量设计保存在历史目录；查该版的实际成员、有效标签和确认用途，以版本清单为准。[项目入口](../README.md) · [V1 设计归档](history/video-v1/) · [V1 清单](../datasets/video-V1/manifest.json)
