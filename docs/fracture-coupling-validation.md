# 第一阶段后续：离散参数组合验证

本文用于九条单参数变体接受之后、批量训练视频制作之前，说明本轮组合选择和检查用途。沿用 [第一阶段专项设计](fracture-variation-stage1.md)；结果、候选及待办仅在 [README](../README.md) 和 [总索引](../outputs/index.json) 维护。本轮制作已获用户“继续下一步”授权，组合效果仍须逐条验收。

## 选择与适用边界

选取七条组合，不做参数笛卡尔积。颈缩、伸长、位置和脱粘档位来自已接受的单参数视频；事件时间来自已确认的12／15／17秒离散设计。时间在各模板上的资格检查与用户接受分别记录。

| 模板 | 组合 | 主要类别／位置保持 |
|---|---|---|
| 金属圆棒韧断 | A=2，最终贯通丧失12秒 | 韧性断裂／标距内 |
| 金属圆棒脆断 | 材料破坏中心+0.75，15秒 | 脆性断裂／标距内 |
| 高分子大伸长 | 伸长增量×0.85，17秒 | 韧性断裂／标距内 |
| 高分子窄平条 | 破坏材料分数0.55，12秒 | 脆性断裂／标距内 |
| 高分子半脆半韧 | 伸长增量×1.15，15秒 | 半脆半韧断裂／标距内 |
| 复材低位脆断 | 材料破坏中心−1.95，12秒 | 脆性断裂／标距外非根部 |
| 复材同步脱粘 | 长度×0.8、开口×1.2，15秒 | 界面脱粘／标距内 |

每片20秒、30fps、600帧，固定模板原相机和照明。这里的时间是模拟事件时间，数值为作者坐标与增量控制量，均不作为源实验实测。陶瓷当前仅有已接受时间变体，继续复用；不为形成组合引入未核验的位置。薄膜、金属平板的未知主模式，以及暂停的爆炸性类别不纳入本轮。

## 制作与验证顺序

1. 在相同模板的默认形变／位置条件下，先对选定事件时间执行600帧单参数资格检查。核对完整阶段重定时、夹口连接、实际材料量和断后条件；资格不通过则阻断依赖的组合。资格检查通过不表示该时间成片已由用户接受。
2. 对组合另做600帧检查和关键状态预览。保持首次开裂前与最后贯通前的测量区分，完整裂区的类别边界，以及原生边连接、重合界面几何连接和可见分离的区别。单参数检查不代替组合检查。
3. 高分子大伸长17秒组合的有限衰减须在20秒结束前停止；半脆半韧实际伸长扣除裂缝开口，保持无明显颈缩及快速脆断。复材断裂与脱粘必须同时开始，末态完全断裂且停止。
4. 编码后核对帧数、时间、完整解码及校验值，独立复核材料行为与标签；主Agent实际打开最终视频及必要关键状态。失败返工，不用修改标签掩盖制作问题。
5. 候选保存于`_work/coupled-stage1-20261009/`，同名JSON保存完整新配置、基准关联、来源、观察、假设、未知、资格／组合实测、事件及核验范围。清除基准接受状态的继承，等待用户对具体组合视频的效果与标签确认。

## 标签和后续边界

六组模拟生成／验收标签沿用第一阶段定义。整段20秒的下游标签预览遵循实际`tensile-vlm/v4.1`契约四字段：`clip_state`、`fracture_mechanism`、`fracture_site`、`special_case`。包含断裂事件的整段使用“发生断裂”；精确事件时间属于模拟元数据。未来切片仍按实际输入区间重新标注，本轮不改切片或训练接口。

组合技术通过、组合视频接受、连续范围和训练发布分别记录。当前少量离散组合不批准连续范围或任意混搭；待组合验收后，再安排批次数量及正式训练输出。裂面倾角、曲折程度、扩展速度、新断后运动及跨位置类别首例仍按原专项设计的后续边界处理。
