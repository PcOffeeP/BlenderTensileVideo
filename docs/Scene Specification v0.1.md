# Scene Specification v0.1

## 1. 基准场景定义

| 模块 | v0.1 固定设计 |
|---|---|
| 试样 | 扁平哑铃形板状试样 |
| 外观材质 | 中性灰、轻微金属反射、无强高光 |
| 试验机 | 两个夹具 + 上下局部横梁 |
| 拉伸方向 | 沿 Blender `Z` 轴竖直拉伸 |
| 相机 | 正面、固定、完整覆盖上下夹具和试样 |
| 背景 | 浅灰或中性灰，无纹理干扰 |
| 光照 | 稳定柔光，突出试样轮廓 |
| 画面质量 | 854×480、30 FPS，首版无抖动和模糊 |

---

## 2. 试样规格

### 2.1 形状模板

模板名称：

```text
flat_dogbone_v1
```

采用归一化尺寸，不绑定具体 ASTM/ISO 标准：

```text
标距段宽度 W                 = 1.0
标距段长度                   = 4.0 W
夹持段宽度                   = 1.8 W
试样厚度                     = 0.15 W
肩部过渡圆角半径             = 0.8 W
单侧夹持段长度               = 1.5 W
```

试样必须明确包含：

```text
上夹持段
上夹具根部区域
肩部过渡区
标距段
肩部过渡区
下夹具根部区域
下夹持段
```

这样后续才能构造并识别契约中规定的三种断裂位置：

- `inside_gauge`
- `outside_gauge_non_root`
- `grip_root` 

### 2.2 几何约束

- 试样中心轴必须与 `Z` 轴重合；
- 网格在标距段和肩部区域需要加密；
- 试样初始状态必须连续、无裂缝、无穿模；
- 夹具只能遮挡夹持段，禁止遮挡整个夹具根部和肩部；
- 首版禁止使用圆棒、纤维束、薄膜或复杂复合材料试样。

## 3. 材质规格

模板名称：

```text
neutral_brushed_metal_v1
```

建议初始参数：

```json
{
  "base_color": [0.45, 0.45, 0.45, 1.0],
  "metallic": 0.8,
  "roughness": 0.5,
  "anisotropic": 0.1
}
```

这里的 Blender Material（材质节点）只控制**视觉外观**，不代表真实材料本构。韧性断裂、脆性断裂等力学行为由后续动画模板控制，不能通过材质节点自动推导。

硬约束：

- 禁止镜面反射遮盖颈缩和断口；
- 禁止使用鲜艳颜色区分断裂模式；
- 禁止让某种颜色与某个标签固定绑定；
- 首版不加入锈蚀、涂层、划痕和复杂表面纹理；
- 试样与背景必须有稳定的轮廓对比。

## 4. 试验机构造等级

建议把设备复杂度定义为三个等级：

| 等级 | 内容 | 当前是否使用 |
|---|---|---|
| L0 | 只有试样，没有夹具 | 禁止 |
| **L1** | 上下夹具 + 局部横梁 | **v0.1采用** |
| L2 | 增加立柱、机架、保护罩等 | 后续扩展 |
| L3 | 完整万能试验机和实验室环境 | 暂不需要 |

v0.1 的 `machine_level=L1` 至少包含：

```text
Grip_Upper
Grip_Lower
Crosshead_Upper_Partial
Crosshead_Lower_Partial
```

每个夹具可以简化为左右两块夹爪，但需要清楚显示：

- 试样进入夹具的位置；
- 夹具口边界；
- 夹具根部区域；
- 上下夹具处于同一轴线。

暂时禁止构造：

- 完整机架和立柱；
- 控制面板、显示器；
- 品牌标识和文字；
- 液压管路和大量螺栓；
- 力—位移曲线叠加；
- 与断裂识别无关的实验室物体。

**原因是完整设备会占用画面并引入背景捷径，而夹具又不能省略，否则无法判断断裂位置。**

## 5. 相机和构图规格

模板名称：

```text
front_fixed_v1
```

构图要求：

- 相机光轴基本垂直于试样正面；
- 上下夹具必须同时完整可见；
- “夹具—试样—夹具”整体占画面高度约 `75%～85%`；
- 标距段占画面高度约 `30%～45%`；
- 试样中心与画面中心偏差不超过画面宽度的 `5%`；
- 试样任何阶段不得超出画面；
- 标距段、肩部和夹具口边界必须可辨；
- 首版相机禁止移动、缩放和旋转。

项目后续以实际帧窗口作为模型证据，因此夹具、标距段和断裂位置不能只在某一帧可见，而应在整个视频中保持有效构图。

## 6. Codex 使用的场景配置

第一版不让 Codex直接修改大量底层数值，只允许引用冻结模板：

```json
{
  "scene_spec_version": "tensile-scene/v0.1",
  "scene_profile_id": "metal_flat_dogbone_l1_front_v1",

  "specimen_template": "flat_dogbone_v1",
  "material_profile": "neutral_brushed_metal_v1",
  "machine_template": "dual_grip_machine_l1_v1",
  "camera_profile": "front_fixed_v1",
  "lighting_profile": "soft_neutral_v1",
  "background_profile": "neutral_gray_v1",

  "tensile_axis": "Z",
  "moving_component": "Grip_Upper",
  "fixed_component": "Grip_Lower"
}
```

Codex 在首个 Golden Prototype 中禁止自行改变：

- 试样类型；
- 试验机等级；
- 相机角度；
- 背景样式；
- 材质颜色；
- 夹具结构。

## 7. 场景生成工作流

Codex 每次先执行场景阶段，再进入动画阶段：

```text
读取 Scene Specification
        ↓
清空并初始化 Blender 场景
        ↓
创建试样、夹具和局部横梁
        ↓
应用材质、背景和灯光
        ↓
设置固定相机
        ↓
生成初始画面预览
        ↓
执行 Scene Gate 检查
        ↓
场景通过后，才加载拉伸与断裂动画
```

Scene Gate（场景门禁）至少检查：

1. 试样、上下夹具均存在且同轴；
2. 标距段、肩部和夹具根部均可辨；
3. 夹具没有错误遮挡或穿透试样；
4. 试样轮廓清晰，没有过曝高光；
5. 相机画面无裁切，构图比例符合要求；
6. 场景中不存在无关文字、曲线和装饰；
7. 所有场景修改已经固化到脚本或配置，而非只保存在当前 `.blend` 文件中。
