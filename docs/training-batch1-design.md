# 首批新增训练视频设计

## 所在阶段与目标

本设计用于27条基础、单参数及组合视频接受之后，首批新增模拟视频制作与训练数据输入准备之前。它规定本批的数量、断裂参数候选、检查和交付边界；全局材料行为、标签语义及文件职责继续遵循 [DESIGN](../DESIGN.md)，参数含义沿用 [第一阶段设计](fracture-variation-stage1.md) 和 [组合验证设计](fracture-coupling-validation.md)。运行结果和待办仅维护于 [README](../README.md) 与 [总索引](../outputs/index.json)。

用户于2026-10-09确认以下设计取舍：新增约60条，先验证批量流程；按断裂行为及有效变化空间分配；新数值选用已接受端点之间的离散档位，再组合事件时间。此次授权为设计文档，不包含新视频制作或下游训练实施。

成功表现是：每条新增视频具有可追溯的断裂参数差异，画面及核验标签一致，配置与来源自足，用户接受后可作为下游数据源；不得将重复渲染、文件数量或标签格式通过当作行为覆盖或训练收益证明。现有27条作为参考和已接受成果，不计入本批新增60条，不重新渲染，也不自动混入本批训练交付。

## 方案权衡与风险处置

选择有限离散档位，能增加断前伸长、颈缩、破坏位置、同步脱粘与时间的变化，同时将逐片验收控制在首批约60条。代价是新增值仍需要完整材料检查，且中间档位可能只产生很小的视觉差异；已接受端点不保证中间值自然或组合可行。有效新增按变化轴分别判定：非时间轴选取同模板、相同事件时间设置的明确参照，对齐阶段和材料状态后做实际测量比较与成片查看；组合中混有时间变化时，同样分别比较非时间轴与时间轴，不能把时序错位当成形态差异。纯时间轴比较各实际事件落帧及完整阶段演化，可计为时序独立配置，但不增加机制或形态覆盖。每条配置记录参照ID及双方完整配置、变化轴、阶段对齐方式，以及实际测量和画面差异结论。不要求跨材料统一差异阈值；参数数字、实现版本或渲染噪声变化本身不能代替可判读差异。差异不足的候选剔除，允许实际交付不足60条。

若有效差异判定或资格诊断需要额外对照，只将其作为资格／诊断证据，不扩大上述60条交付候选，不计有效新增，也不重新渲染现有27条已接受视频。执行记录和比较细表保存在本批`_work/`，必要参照、测量与差异结论写入各候选配套JSON；README/index继续作为唯一结果和待办入口，不另建候选总表。

备选方案是仅组合已接受原数值，制作和回归压力较小，但新组合数量及行为差异有限，可能达不到60条；它可作为某模板新档位失败后的收缩方案，不能被写成已经通过。用户选择本批新增中间离散档位；失败时允许减少交付，而非自动拓宽边界。

材料平均配额会提高陶瓷代表性，但当前陶瓷只有时间轴，生成15条易使大量样本仅有小时间差，并挤占已具形变依据的模板。用户选择按有效行为空间分配；材料不均衡是本批接受的设计代价，实际训练配比及采样权重由下游另评估。

主要失败方式及处置：

- 时间、伸长或位置耦合造成出框、夹口脱离、穿透、错误贯通或断后持续运动：阻断该配置，不移动镜头、改变标签或制造异常样本来掩盖问题。
- 位置变动使完整裂区越过标距／夹根边界：剔除该候选；本批不新增位置类别。位置按作者标距定义，源正式标距未知继续保留。
- 半脆半韧出现新的明显颈缩，或复材先脱粘后断裂／只有脱粘没有全断：返工或剔除；不得改主要类别通过。
- 金属重合几何连接、mixed断后小片零开口接触及复材固定截面体积近似：沿用已说明的定性边界，分别测量原生连接、几何接触与实际体积，不升级为微观粘结、不可压缩或本构证明。
- 参数与成片、来源、标签或索引脱节：以最终MP4和JSON字节校验值绑定；失败重做该片，旧接受成果不自动替换。
- 下游把整片标签复制给每个切片，或同一来源家族跨训练／评测集合导致泄漏：交付明确整片标签作用区间和来源家族，切片重标及划分由现有下游流程显式处理；本项目不默认指定split或声称无泄漏。

## 制作验证与接受边界

1. 冻结本批实际使用的可复用入口版本、源码SHA、完整默认配置、各模板实际阶段时间映射和来源绑定。旧视频继续记录其实际实现版本，不能用当前入口版本反写旧片。
2. 新非时间档位先在对应默认条件下做单参数资格，新时间在同模板默认形变／位置下做资格。显式记录资格节点→候选节点的依赖：每个候选绑定所需单参数资格及完整组合检查，不用数值位于已接受端点之间来代替资格。资格复用绑定实现版本、源码SHA、完整配置和检查范围；这些绑定一致且完整证据覆盖本次要求时直接复用，不重复运行，同一配置的单参候选与资格不机械做两遍。旧视频接受不能代替本次所需资格。
3. 组合另做600帧实际求值检查：夹口连接、实际图贯通、同一材料段长度／截面／适用体积、全裂区位置、事件时序、断后停止／衰减、间隙与局部穿透、画框。金属A须测颈部最小截面积比；高分子倍率比较扣除裂口增量；脱粘范围和开口从实际网格测量。
4. 单参数资格失败，阻断所有依赖该资格节点的候选；完整组合失败，先仅阻断该完整组合。只有证据指向模板或检查器共因时，才扩大到受同一问题影响的资格和候选。例如狗骨倍率0.90的单参数资格失败会阻断表中依赖它的16、16.5、17秒候选；若仅0.90／17秒组合失败，先阻断该组合，不自动否定另两个组合或所有17秒配置。修复后重验受影响范围，重新绑定版本、源码SHA、完整配置和检查范围，再恢复对应依赖；其余不受影响的工作继续。资格通过不是独立时间或参数视频的用户接受。
5. 成片核对600帧、30fps、20秒、时间戳、完整解码和JSON一致性；独立复核材料行为及标签，主Agent实际打开最终视频及必要关键状态。
6. 首批新增视频逐条交用户查看效果与标签。全部技术通过也不能代替这一接受；接受后才复制到current，核对MP4字节并同步README/index。后续批次抽样规则不在本批扩大。

候选、返工、场景、帧和检查证据保存在`_work/<本批任务>/`；配套JSON自身保存完整配置、来源、时间映射、观察、假设、未知、实际测量、预期／核验标签、检查范围和接受记录。README/index仅维护实际结果，不预先登记60条为已生成或可接受成果。

## 标签与下游输入交付

交付有三个职责层次：

- 每条MP4及同名JSON：本项目的成片交付单位。JSON保留六组模拟生成／验收标签，材料、机制、位置的来源及未知分别保存；事件秒数和参数值属于模拟元数据。
- 本批索引引用及整片V4.1标签预览：按实际接受条目形成交付清单，引用总索引和current文件，不另建机器总索引。导出清单与预览保存于本批工作目录，并记录清单版本、视频／JSON SHA、源码／完整配置SHA、来源ID／家族、标签契约版本／hash及整片作用区间。未接受条目不能进入已接受交付清单。
- 下游输入准备：由现有mVllm_2显式版本流程办理source输入、标签映射、split、ROI、媒体／预处理pins、切片和复核。本项目当前index与六组JSON不是该流程可直接消费的inputs文件；本批只明确交付可追溯的数据源，不声称已完成适配或训练发布。

整片标签预览固定使用实际`tensile-vlm/v4.1`的四字段：`clip_state`、`fracture_mechanism`、`fracture_site`、`special_case`；既有验证器检查字段和值。整片20秒含破坏事件，`clip_state=发生断裂`，机制按核验主要类别，位置按对应契约值，无异常时`special_case=null`。精确时间不新增为模型输出字段；未来切片依据实际输入区间重标，不复制整片末态。
