# 视频生成参数与测量规范

制作批次时先按 [DESIGN 第 2 章](DESIGN.md#2-拉伸行为规则与参数搭配)确定材料、试样和加载条件下适用的行为，再从下列十类 64 项中选取本批参数。记录所选变量、固定项、需要联动的量和核验方法。

表中的值是**候选选择或示例**，不是全部已经实现或通过验收的范围。具体入口、已接受样片与待审候选分别见[生成工具说明](../generator/README.md)、[项目入口](../README.md)和[V1 清单](../datasets/video-V1/manifest.json)。选项缺少依据时记“未知”，事件或对象不存在时记“不适用”；六组标签的允许值仍以 [DESIGN.md](DESIGN.md) 为准。

## 模板代号

代号用于说明参数的适用对象，对应项目已有基准样片的分类；不因列入本表而批准整个样式、参数范围或新组合。改变材料、试样结构或主要行为后，如无匹配基准，应另按来源和目标设计，不把历史测试来源用作新模板。

| 代号 | 材料与行为基准 | 场景入口 |
|---|---|---|
| M1 / M2 | 金属圆棒颈缩韧断 / 小变形脆断 | [metal_initial.py](../generator/metal_initial.py) 的 `--style ductile` / `--style brittle` |
| M3 | 金属平板有限变形断裂 | [metal_flat.py](../generator/metal_flat.py)，传入来源记录 `--reference` |
| P1 / P2 | 高分子狗骨大伸长 / 薄膜夹口根部断裂 | [polymer_initial.py](../generator/polymer_initial.py) 的 `--style dogbone` / `--style film` |
| P3 / P4 | 窄平条脆断 / 均匀拉长后快速断裂（项目半脆半韧） | [polymer_brittle.py](../generator/polymer_brittle.py) / [polymer_mixed.py](../generator/polymer_mixed.py) |
| C1 / C2 | 复材近下夹口脆断 / 断裂与界面脱粘同步 | [composite_initial.py](../generator/composite_initial.py) 的 `--kind brittle` / `--kind debond` |
| K1 | 陶瓷狗骨小变形脆断 | [ceramic_initial.py](../generator/ceramic_initial.py) |
| 补充样片 | 局部开裂 / 未夹紧 / 爆炸性断裂 | [ceramic_crack.py](../generator/ceramic_crack.py) / [unclamped_initial.py](../generator/unclamped_initial.py) / [explosive_fracture.py](../generator/explosive_fracture.py)；按各自依据审核 |
| 其他新样式 | 尚无匹配基准的材料或行为 | 先确定来源、目标与适用性，再选实现 |

下表“全部”指上述基准及后续适用的新样式；具体候选值仍须匹配该模板。带“基准”的选项指所选模板的固定配置。

独立合成系列的陶瓷脆断和金属韧断使用独立设定的场景，不从上述真实来源基准继承画面或动作；其适用参数和候选状态按自身配置及项目入口核验。

## 测量与时间对应

| 对应参数 | 如何测量与记录 |
|---|---|
| B6、D2 标距与伸长 | 确定初始材料坐标、同一对标记点和标距依据，注明材料路径长度或轴向投影长度。伸长比为 `L(t)/L(0)`，伸长增量为该比值减一。D2 的倍率作用于伸长增量；测量时区分材料伸长与裂口张开，夹具位移单独记录。 |
| D4–D6 颈缩 | 对同一材料截面计算 `A(s,t)/A(s,0)`，记录最小完整截面的位置、面积比和颈缩区宽度的取法。分别查看首次开裂前和最后仍贯通的状态，截面已切开时注明该次测量不可用。裂缝面积及残余连接截面排除在颈缩测量之外。 |
| E3、E4、E9–E11 位置与脱粘 | 在初始材料坐标中检查**整个**破坏区与标距、肩部、夹口的关系。对同步脱粘样式，分别测界面打开和断裂的起始帧、脱粘长度与开口，并核对末态连通性。 |
| G1–G5、J3 事件与帧号 | 分开记录首次开裂、最终失贯通、首个可见全断帧和断后停止；注明窗口外或不可判的事件。恒定帧率下，用零起算的输出帧序号除以帧率得到显示时间；若场景编号从 1 起，先减 1。来源时间另记。末帧时间戳与整片播放时长相差一个帧间隔。 |

## 共同约束

- 模板、材料、形状与破坏类别必须匹配；改变结果、位置类别或异常条件时，作为新组合重新核验。
- 伸长、颈缩、试样截面和夹具位移应作用于同一材料段，不能只修改画面外形；正常夹持时，试样与夹口保持连接。
- 裂纹起始、最终失贯通、断后停止和观察时长相互关联。来源时间、模拟时间及编码后的帧号分别记录。
- 单条视频内相机位置、朝向、视场和成像尺度保持固定。更换角度或风格后仍须检查整个过程和所需视觉线索。
- 有限样片通过不代表连续范围或所有组合通过；预期标签和核验标签分开记录。
