# 第一阶段：断裂参数变化与离散候选验证

本设计用于已接受基础视频之后、批量训练视频之前，明确首轮断裂参数化的对象、候选值、耦合约束和验收方法。目标是增加可判读的断裂行为差异，先核验单参数变化，再组合已通过的离散参数；不以镜头、照明或背景变化代替断裂行为扩展。

本阶段参数选择已由用户确认。下面的数值是待制作、待核验的离散设计候选，不是已通过的材料参数范围；没有本构标定，不证明真实材料的定量响应、连续范围或任意参数组合成立。

全局原则与六组标签见 [DESIGN.md](../DESIGN.md)，结果和待办见 [README.md](../README.md)，成片与候选状态见 [outputs/index.json](../outputs/index.json)，可复用入口及版本见 [生成工具说明](../generator/README.md)。本文不维护运行进度、成片接受状态或候选总表。

## 1. 阶段范围

第一阶段开放断前伸长、金属圆棒颈缩程度与集中范围、同一位置类别内的破坏位置、断裂事件时间，以及同步脱粘的长度与开口。变化保持基础模板的六组标签约束、材料行为和既有断后条件。

薄膜夹口根部断裂与金属平板有限变形断裂的主要类别仍无法确认，本阶段不将其用于确定主要模式的监督标签。爆炸性断裂制作继续暂停；纵向细束展开或毛束般分离不作为有效爆炸性模板。

## 2. 测量定义

所有伸长、截面和位置测量都使用初始材料坐标和可追踪材料点。夹具行程不能直接代替标距伸长。作者定义的模拟标距与来源正式标距分开，后者无法确认时继续记录未知。

“断前”分为两个测量时点，分别记录：

- **首次开裂前**：首个可核验开裂事件前的最后一个未裂状态。
- **最终失去贯通连接前**：加载端与固定端之间最后仍有实际材料连接的状态。

快速突断模板的两个时点可能相同，但不能先行合并定义。若可见裂纹与实际连接变化的时刻不同，分别记录可见事件和网格判定，不用裂口出现自动推定完全断裂。

伸长比按同一对材料标记点的长度计算：`lambda_g = L_g(t) / L_g(0)`；伸长增量为 `lambda_g - 1`。需要说明采用材料路径长度还是轴向投影长度，不混用二者。局部材料段的长度变化另行记录，不能只测整片包围盒。

颈缩程度按同一材料截面的面积比 `r_A = A(s,t) / A(s,0)` 描述，并记录最小完整截面、其材料位置和颈缩区宽度。面积测量排除裂缝、切开的裂面和残余连接截面；否则裂区面积减少会被误算为颈缩。最终失去连接前若颈缩中心已在裂区，标记该测量不可用，保留首次开裂前的有效测量，不编造替代值。颈缩区宽度的材料坐标范围与选取规则写入配置，不能用画面“强／弱”代替量化定义。

## 3. 离散候选与耦合约束

### 3.1 高分子断前伸长

对大伸长和半脆半韧基准，候选为基准伸长增量的 **0.85、1.00、1.15倍**。缩放的是伸长增量，目标表达为 `lambda_candidate - 1 = k * (lambda_baseline - 1)`，不是直接把总长度乘以该系数。

生成器中的作者伸长曲线与最终材料点测量值分别保存；不能因为输入系数正确就宣称实际伸长正确。夹持段保持连接，过渡区与加载端位移随材料段长度耦合。半脆半韧变化后仍须满足无明显颈缩和最终快速脆断；若出现可判读的局部颈缩，不能继续沿用原类别让样片通过。

小变形脆断本阶段不开放大伸长档位。不得把柔性大伸长动画直接套到脆断试样上。

### 3.2 金属颈缩程度与集中范围

金属圆棒 `ductile` 的局部轴向伸长增量控制量 **A候选为2、3、4**，对应现有入口 `--neck-local-stretch-amplitude`。它不是颈缩百分比，也不是实测应变或材料本构参数；实际程度由完整截面面积比核验。

A=4用于与固定基准比较；A=2此前检查只支持关键状态与网格的有限范围，不能代替新成片验收；A=3须按新候选核验。工程输入守卫 `0 < A ≤ 4` 不批准这一连续材料或视觉范围。

颈缩区宽度和中心也属于本阶段设计对象，但不在此给出未经比较的统一数值。宽度候选需围绕各模板固定基准定义离散值，保持同一材料段的长度、截面和适用体积近似；局部伸长变化必须通过材料坐标积分同步驱动加载端。不能只把腰部缩细，也不能用扩大断面间隙替代更明显的颈缩。

第一轮分别改变程度、宽度或中心；组合时再次核验，不能由三个单参通过推定耦合组合通过。

### 3.3 同位置类别内移动破坏区

候选为基准位置、向一侧偏移、向另一侧偏移。位置定义在初始材料坐标中，移动完整破坏区及其相关变形场，不通过平移已断片实现。

偏移距离依各试样标距、肩部、夹口及裂区宽度确定，不给八个模板套统一距离。位置核验覆盖整个裂区边界、斜裂两端、脱粘范围和最终断口，不能仅检查裂区中心。复材低位脆断必须仍处于标距外非根部，不能接触夹口根部；标距内模板的完整裂区保持在该类别内。

跨标距边界、进入夹口根部或改变完全断裂结果属于新标签组合，应另做首例并核验，不混入常规位置变体。

### 3.4 事件时间与阶段时长

以 **20秒视频**为本阶段起点，**最终失去贯通连接**的候选时刻为 **12、15、17秒**。各时刻跨模板安排，不能让某个材料或类别始终固定在同一时刻。

每条记录加载开始、首次开裂、脱粘开始（适用时）、最终失去贯通连接、可判读完全分离及断后停止等事件。按模板既有阶段重定时加载、形变和破坏过程，保持事件顺序；不是简单平移一个断裂关键帧。陶瓷等已有裂纹发展阶段保留，不能为匹配时间把它们全部压成一帧；半脆半韧最终快速脆断的条件保持。

断后仍需足够观察时长。有限衰减模板须重新核验衰减结束与停止时刻；静止模板不得因时间调整增加刚体平移、缩短或摆动。源实验时间与模拟演示时间分别记录，候选时刻不表示真实材料断裂耗时。

帧与时间换算使用实际编码的起始帧和帧率，例如帧号从1开始时 `time_s = (frame - 1) / fps`。配置、求值网格与编码视频的事件时刻须一致。

### 3.5 同步断裂与脱粘

沿试样长度的脱粘范围和界面打开幅度，分别试基准的 **0.8、1.0、1.2倍**。先单独改变长度，再单独改变开口；各离散值通过后才组合。

破坏与脱粘在同一事件中同时开始。禁止为增加可见性加入“先脱粘、后断裂”的独立阶段。共同破坏位置移动时，两种现象的范围随之协调；两者均须可判读，末态保持完全断裂。检查界面开口、厚度、裂区长度、夹持边界、穿透与实际连通性；若放大导致越界或不合理变形，缩小候选或返工，不能自动更换标签。

## 4. 入口实现与固定基准回归

参数入口必须按适用模板实现：金属圆棒的A、颈缩区宽度、中心、破坏位置与事件重定时；高分子的适用伸长、位置与时间；复材的位置、时间及同步脱粘范围／开口；陶瓷的位置与时间。参数必须改变实际求值场景，不能只改配套JSON。具体实现版本和命令见生成工具说明，完成状态与候选仅在README和index维护。

每个入口保存实现版本、参数含义与单位、默认值、适用模板、工程守卫、完整选定配置和来源。默认值承担固定基准回归，不能因新增参数入口自动替换已接受视频。

金属已接受颈缩视频记录原实现1.0.1，而可复用代码已为1.1.0。实现时需保留这一版本差异，按原同名JSON与自包含场景追溯；新版本不能被反写成旧成片的生成版本。已有有限帧默认值比较仅支持其实际检查范围，参数化后应检查连续求值过程及最终编码，记录与固定基准的差异和容差。其他入口同样按适用分支版本追溯，不能只以文件的最新版本号选定当前视频。

配置不得依赖可清理的 `_work/` 输入。基准回归至少覆盖材料点轨迹、截面、夹口连接、裂区位置与事件、断后条件，以及必要的成片可见性。新参数候选与基准回归分别记录。

## 5. 生成记录与训练标签

每条视频配套JSON保留六组预期标签及逐项核验标签：材料类别、断裂结果、单一主要破坏类别、断裂位置、夹持异常、拍摄异常。配置、实际测量、时间映射、观察、作者假设、科学未知、来源及验收范围另行保存，不增加第七个主标签组。

材料身份来自来源资料或用户明确确认，不能因颜色、纹理或模型外观判定。断裂结果、可见过程、位置和异常依据最终成片及实际检查；参数档位描述生成目标，不能直接充当训练真值。制作错误应返工，不能作为目标异常样本或自动改标签收录。

六组标签用于整条模拟视频生成与验收记录，**不等于下游训练schema**。训练JSON／JSONL须按现有微调接口映射已核验信息；具体字段与答案结构以实际接口为准，未核对接口时不能宣称已输出兼容训练文件。切片及 `clip_state` 等适配遵守下游规则，切片事件时间与结果按实际输入重新计算，不复制整片末态。本阶段不新增训练字段、不改切片规则，也不把成片接受等同训练发布。

## 6. 制作顺序与验收条件

按单参数离散候选、已通过离散参数的耦合组合、批次数量与训练输出的顺序推进，不做全部参数的笛卡尔积，不固定每模板三条来凑数量。具体候选、执行结果与待办仅在README和index中维护。

每条候选满足以下条件后才进入适用的人工验收：

1. 来源与行为约束匹配；观察、作者配置、未知分别保存，参数变化未越过模板或标签边界。
2. 实际求值网格全程检查夹口连接、连通性和事件，同一材料段的长度／截面及适用体积近似、连续性、间隙与穿透；组件数和关键帧预设不能替代实际测量。
3. 首次开裂前与最终失去贯通前分别记录有效测量；断裂位置检查整个裂区；同步脱粘核对两种现象的起始与最终完全断裂。
4. 断后满足固定模板的停止或有限衰减条件，无新增无依据的动作。
5. 最终视频可播放，编码、帧数、时长、事件时间与JSON一致；画面清楚呈现所需视觉线索。
6. 按项目约定完成材料行为与标签的独立复核；主Agent实际打开最终视频和必要关键状态；首批变体逐条由用户看效果与标签。技术通过不代替用户接受，也不证明连续范围已通过。

候选与检查证据保留在 `_work/<任务>/`；适用检查并由用户接受后，视频和同名JSON才收录到 `outputs/current/`，核对字节校验值与总索引。单条接受、样式范围确认、参数组合确认和训练发布分别记录。

## 7. 第二阶段边界

裂面倾角、裂线曲折程度、裂纹扩展速度以及新的断后运动参数留待第二阶段：先核对对应真实视觉依据，再分别设计、制作和核验。不能随意给脆断增加渐进撕裂，也不能通过扩大断面间隙增强断开效果。

改变位置类别、破坏结果或异常条件的首例，尚缺行为依据的样式，以及爆炸性断裂的恢复，均不由本阶段参数组合自动覆盖。若后续局部设计不影响全局范围、标签语义或生成原则，另在 `docs/` 中说明其所属阶段、用途、适用模板与约束；仅将影响全局的规则提炼回DESIGN。
